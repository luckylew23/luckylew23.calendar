# 日历

侧边栏里一个月历，把观察角日历插件的做法搬到 Textus：有笔记的日子标出来，点某一天就选中它，日历下面列出那天写过的笔记；这一天的日记没有就点一个按钮用模板建。

- **插件 › 打开日历** 把日历开成一个标签页；侧边栏的 **日历** 标签是同一张日历，两种宽度都能用。
- 每天下面的点表示那天写了多少字：默认每 250 字一个实心点，最多五个，写过字的日子至少一个点；还有没做完的待办时，再多一个空心点。字数为零但有待办的日子，只画一个空心点。
- **点某一天只是选中它**，不会新建任何东西：日历下面列出那天的笔记，最上面是这天的日记，其余按修改时间从新到旧排，每行前面一个小圆点（日记是主题色），右边是写它的时间。点一行就打开那篇笔记，**Ctrl 或 ⌘ 加点击**在分屏里打开。
- 那天的笔记越多，格子底色越深（一两篇浅一点，五篇以上最深），一眼能看出哪天写得杂。
- 那天还没有日记时，列表上方出现 **新建日记**：按库的模板新建并打开，设了「新建前先问一句」会先问一声。**Ctrl 或 ⌘ 加点击日历上的某一天**，直接建好那天的日记并在分屏里打开。
- 设置里打开周数后（默认打开），每月左边一列写着周数。**点周数选中整周**，日历下面列出一周里写过的笔记（行首带日期）；**Ctrl 或 ⌘ 加点击周数**才打开或新建那一周的笔记。
- **插件 › 打开今天的日记**、**在日历里定位当前笔记那一天**（Mac 上同样可用）跟着当前笔记走；方向键、Home/End、PageUp/PageDown 在日历里移动，Enter 选中聚焦的那天。
- 月份名点一下，用 Textus 自己的日期选择跳月。

## 设置

- **一周从哪天开始**：跟随语言、周日或周一，与周数的算法一致。
- **多少字一个点**：默认 250，设 0 关闭点，改为标出有笔记的日子。
- **显示周数**：默认打开；点周数选中整周，Ctrl/⌘ 点打开那一周的笔记。
- **新建前先问一句**：默认打开；关掉后新建日记不再询问。

## Obsidian 库

在 Obsidian 库里按库自己的日记设置来：文件夹、命名格式和模板都读库的（Textus 已经把这些解析好），Textus 不会改动这些设置；库里没有日记设置时，笔记放在库的最上层。每次新建都用库的模板填好 `{{date}}`、`{{title}}`。每周笔记跟随 Periodic Notes 的设置。

## 与 Obsidian 版的差别

- 点一天是选中它并列出那天的笔记，Obsidian 版是直接打开（没有就新建）；这里新建是独立的 **新建日记** 按钮，Ctrl/⌘ 点击仍然直接开会话分屏。
- 下面那份列表和底色深浅是新加的：Obsidian 的月历只画点，不列笔记，也不按笔记数改底色。
- 点周数在这里是选中整周、列出这一周写的笔记；Obsidian 版是直接打开每周笔记（这里要 Ctrl/⌘ 点）。
- 回到本月用 **今天** 按钮，Obsidian 版是一个小圆点；标题点是 Textus 自己的月份选择器。
- 每周笔记只用库里的设置，不自己另立一套每周笔记设置。
- 日期名、周首日和星期名都跟随 Textus 的语言（`textus.dates` / `Intl`），不读 Obsidian 的 locale 覆盖。
- 节假日、标签、外链菜单这类社区扩展点没有实现，只保留字数点与待办空心点。

## 权限

需要读写当前文件夹里的文件：找已有的日记、数它们的字数、按模板新建，以及列出那天改过的笔记。还要读当前打开的是哪篇文档，好在日历里定位它。需要 Textus 1.4.3 或更新版本。
